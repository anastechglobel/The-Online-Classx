### 🖥️ 2. ADMIN PANEL IMPLEMENTATION (`admin.html`):

#### A. Live Classes Tab UI (`#tab-live`):
1. **Header Section:**
   - Title: "Live Classes Studio"
   - Subtitle: "Schedule upcoming streams, broadcast live lectures, and manage recordings"
   - Action Button: `+ Schedule Live Class` (opens `#liveModal`).
   - Quick Filter: Filter by Course, Subject, or Category.

2. **Live Classes Table / Grid:**
   - Visual display showing:
     - 16:9 Thumbnail banner with status badge:
       - 🔴 `LIVE NOW` (Pulsing red badge when active).
       - 🔵 `SCHEDULED` (Blue badge with start date & time).
       - ⚫ `RECORDED` (Gray badge for completed sessions).
     - Session Title, Faculty Name, Linked Course & Subject tags.
     - Fee type badge: `Free (Public)` vs `Paid (Enrolled Only)`.
     - Streaming Mode: `In-App YouTube Player` vs `Direct Deep Link`.
     - Action Buttons: `Go Live / Toggle Status`, `Edit (pen icon)`, and `Delete (trash icon)`.

#### B. Schedule & Edit Live Modal (`#liveModal`):
A clean popup modal covering:
1. **Class Title & Description:**
   - Title input (required).
   - Multi-line textarea for topics covered, homework, and session notes.
2. **Academic Categorization:**
   - Linked Course selector: Dropdown from `/courses` (or "General / Standalone").
   - Subject selector: Dropdown dynamically populated from `/subjects`.
   - Category selector: Dropdown from `/categories`.
3. **Access Control & Fee Type:**
   - Dropdown: `Free (Available to all students)` vs `Paid (Enrolled in linked course only)`.
4. **Streaming Configuration:**
   - Streaming Mode selector: `In-App Player (Embedded inside App)` vs `Direct (Opens in YouTube App)`.

   - Live Start Date & Time picker (`<input type="datetime-local">`).
   - Live Chat toggle switch: Enable / Disable real-time chat for students.
6. **Action Buttons:**
   - "Schedule Now / Update Class" primary button.
   - Calls `saveLive()`, updates Firebase, and triggers automated push notification via FCM topic `all_students`.

### 📱 3. ANDROID CLIENT APP INTEGRATION (Kotlin & Jetpack Compose):

#### A. Live Hub Screen UI (`LiveClassesScreen.kt`):
1. **Header & Category/Subject Filter:**
   - Horizontal scrolling pills for Subjects (e.g., "All", "Physics", "Maths", "Chemistry").
2. **Three-Tier Categorized Lists:**
   - 🔴 **Section 1: Live Now:**
     - Pulsing red "LIVE" indicator with viewer counter.
     - "Join Class Now" prominent button.
   - ⏳ **Section 2: Upcoming Sessions:**
     - Live ticking countdown timer: `HH:MM:SS` (Updates every second).
     - "Remind Me / Set Alarm" button (adds to Android Calendar / local notification).
   - 📼 **Section 3: Past Recorded Classes:**
     - List of previous lectures accessible for revision anytime.

#### B. Access & Lock Gate Engine:
- Before opening a live class:
  - If `class.type == "Free"` -> Instant playback.
  - If `class.type == "Paid"`:
    - Check if student UID exists in `/courses/{courseId}/enrolled_users/{uid}` OR active subscription.
    - If NOT enrolled: Display lock overlay with "Course Required" badge and a single-tap button: "Enroll Now to Unlock Live Class" opening course checkout.

#### C. In-App Video Player Screen (`LivePlayerActivity.kt` / Composable):
- Seamless In-App playback using `YouTubePlayerView` (`com.pierfrancescosoffritti.androidyoutubeplayer:core`).
- Features:
  - Fullscreen toggle with auto landscape rotation.
  - Live stream auto-resume and quality controls.
  - Optional Live Chat panel below or beside video in landscape.
  - Anti-Screen Recording & Screenshot blocking (`FLAG_SECURE`) for DRM protection.
