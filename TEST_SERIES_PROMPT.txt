### 2. ADMIN PANEL IMPLEMENTATION (`admin.html`):

#### A. Test Series Tab UI (`#tab-tests`):
1. Header Section:
   - Title: "Test Series & Quizzes"
   - Subtitle: "Create and manage objective mock tests, quizzes, and assessments"
   - Primary Action Button: `+ Create New Test` (opens `#advancedTestModal`).

2. Tests Table & Card Grid:
   - Clean layout showing Test Title, Subject, Category, Course linkage.
   - Question Count & Total Time badge.
   - Access status: `FREE` vs `PAID/PRO`.
   - Action Buttons: `Edit`, `View Questions`, and `Delete`.

#### B. Advanced Test Creator Modal (`#advancedTestModal`):
A clean, multi-step responsive popup modal containing:
1. Step 1: Basic Details & Configurations:
   - Test Title & Description.
   - Subject & Category Selectors (Dynamically populated).
   - Linked Course Selector.
   - Test Status (Free vs Paid).
   - Paid Options (Price, Discount, Payment Link) appearing if Paid is selected.
   - Timer Input (Seconds per question).
   - Question Entry Method Selector (Three types of test launching systems).
2. Step 2: Question Input Methods (3 Distinct Types Supported):
   - **Method 1: Manual Entry (`setTestMethod('manual')`)**
     - Dynamic list of question rows.
     - Each row has text inputs for: Question Text, Option A, Option B, Option C, Option D, and a Correct Answer Dropdown (a, b, c, d).
     - "Add Question" button to dynamically append new rows.
   - **Method 2: JSON Upload (`setTestMethod('json')`)**
     - Drag & Drop or File Picker for a `.json` file (`<input type="file" accept=".json">`).
     - Reads the file containing a JSON array of objects (format: `[{q, a, b, c, d, ans}, ...]`).
     - Previews the JSON and pushes directly to Firebase.
   - **Method 3: Text / Word Parser (`setTestMethod('text')`)**
     - Large `<textarea>` block for bulk-pasting copied text from MS Word or PDFs.
     - Enforces standard text format logic:
       `Q1. Question text here?`
       `A. Option A`
       `B. Option B`
       `C. Option C`
       `D. Option D`
       `Answer: A`
     - Uses JavaScript Regex/Split (`parseAndFinishText()`) to automatically convert this string into the structured JSON array.
3. Action Buttons:
   - "Save Test and Questions" which builds the array from the chosen method and saves/updates to `/tests`.
