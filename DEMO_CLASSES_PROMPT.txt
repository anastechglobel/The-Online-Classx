Act as a Principal Full-Stack Engineer and Android LMS Architect.

I want to build a complete "Free Demo Classes / Sample Lectures" system for an Educational LMS (Android App + Web Admin Panel).

Admins should be able to manage free demo video lectures from `admin.html` by providing a title, description, thumbnail, video URL (YouTube video or ID), and selecting a playback mode (`In-App` vs `Redirect`).
The Android App must display these demo lectures on the Home screen in a horizontal carousel, as well as in a dedicated "Free Demos" screen. When a student taps a demo class, the app should either seamlessly play the video inside the app using an embedded video player or redirect them to the YouTube app based on the Admin's configuration.

---

### 🛠️ TECH STACK & ARCHITECTURE:
- Frontend Web Admin: HTML5, Tailwind CSS, FontAwesome 6 Icons
- Database: Firebase Realtime Database (`/demo/{demoId}`)
- Real-time Sync: Modular Firebase SDK (`onValue`, `push`, `set`, `remove`)
- Target Android Client: Kotlin, Jetpack Compose or XML Views
- Video Playback: Android YouTube Player library (`com.pierfrancescosoffritti.androidyoutubeplayer:core`) or ExoPlayer / WebView Embed
- Architecture: MVVM (Model-View-ViewModel with StateFlow).

### 📦 1. DATABASE SCHEMA (`demo/{demoId}`):
Each demo class record stored in Firebase Realtime Database must follow this schema:
```json
{
  "id": "-Ndemo_physics_kinematics",
  "title": "Kinematics 1D - Free Demo Lecture",
  "description": "Master the basics of motion, velocity, and acceleration with live problem solving.",
  "thumbnail": "https://storage.example.com/thumbnails/demo_kinematics.jpg",
  "videoUrl": "https://www.youtube.com/watch?v=dQw4w9WgXcQ",
  "playMode": "In-App",
  "createdAt": 1725500000000,
  "updatedAt": 1725500000000
}
```

*Playback Modes (`playMode`):*
- `"In-App"`: The video plays directly inside the Android application without forcing the student to leave.
- `"Redirect"`: The app launches an external intent to open the lecture inside the official YouTube app or Web Browser.

#### B. Video Playback & Routing Architecture (`DemoPlayerActivity.kt` / `DemoPlayerScreen.kt`):
When a user clicks on a `DemoClassCard`:
1. **Extract Video ID Helper:**
   Create a regex helper function `extractYoutubeVideoId(url: String): String?` to support formats:
   - `https://youtu.be/<ID>`
   - `https://www.youtube.com/watch?v=<ID>`
   - `https://www.youtube.com/embed/<ID>`
   - `https://www.youtube.com/shorts/<ID>`
   - Raw 11-character string.

2. **Branching based on `demo.playMode`:**
   - **Case 1: `demo.playMode == "Redirect"`**:
     ```kotlin
     val intent = Intent(Intent.ACTION_VIEW, Uri.parse(demo.videoUrl)).apply {
         // Attempt to open directly in YouTube app if installed
         setPackage("com.google.android.youtube")
     }
     try {
         context.startActivity(intent)
     } catch (e: ActivityNotFoundException) {
         // Fallback to default browser
         context.startActivity(Intent(Intent.ACTION_VIEW, Uri.parse(demo.videoUrl)))
     }
     ```
   - **Case 2: `demo.playMode == "In-App"`**:
     - Navigate to `DemoPlayerScreen(demoId = demo.id)`.
     - In `DemoPlayerScreen`:
       - Embed `AndroidView` holding `YouTubePlayerView` from `com.pierfrancescosoffritti.androidyoutubeplayer:core:12.1.0`.
       - Automatically cue or play the extracted video ID.
       - Display lecture title, full description, and faculty details below the video player.
       - Include a "Join Full Batch" / "Explore Courses" call-to-action button to drive course conversions.

#### C. Dedicated "All Demo Classes" Screen (`DemoListScreen.kt`):
- 2-column Grid (LazyVerticalGrid) or vertical scroll list of all available demo lectures fetched from Firebase node `/demo`.
- Includes pull-to-refresh and empty-state placeholders.
